# Bindu Maligi — Research Software Engineering Portfolio

A distinctive, responsive portfolio tailored to the Student Assistant / Junior Research Software Engineer role at the Center for Humans and Machines, Max Planck Institute for Human Development.

## Preview
Open `index.html` in a browser.

## Before publishing
1. Add your actual LinkedIn and GitHub profile URLs if you want them linked.
2. Add a real repository or demo URL for the Doctor Booking App and requirements-analysis project when available.
3. Confirm your contact details and availability.
4. The portfolio describes WebSocket-based progress/events and asynchronous task handling as planned extensions, not completed production features. Update this only when implemented and tested.

## Publish free with GitHub Pages
1. Create a public GitHub repository named `bindu-portfolio`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to deploy. The public URL will look like `https://YOUR-USERNAME.github.io/bindu-portfolio/`.

The ZIP contains the website and this README. This package is not hosted publicly until you complete the publishing steps.
